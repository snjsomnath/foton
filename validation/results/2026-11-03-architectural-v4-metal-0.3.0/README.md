## This campaign is the reference source

Its converged Radiance references were exported with
`scripts/export_reference_bundle.py` and published as
[`foton-references-corpus4-2026-11-03.zip`](https://github.com/snjsomnath/foton/releases/tag/references-corpus4-2026-11-03)
(SHA-256 `de4be5a59e4b694d0c9f8f5ef697649527e45dd231d9794b23ff7a9f8038417b`).
The Vulkan suite for 0.3.0 and the Metal suite on the final release commit were
judged against that bundle with `--reuse-references`, so every backend in the
release is compared with the same converged references.

## Files

`suite.json` holds every case's full report (what each `*/mf*/report.json`
contained); `suite.md` the status table; per case, `report.md`,
`coefficient_comparison.{json,md}`, `converged_annual.json` and, for the
acceptance model, `stock_comparison/`. Models are regenerated by
`validation/scenes.py` and hashed in each report. Raw stage folders, the
coefficient matrices and the weather cache stay on the machine that ran the
campaign (43 GB), except for what the published bundle carries.
